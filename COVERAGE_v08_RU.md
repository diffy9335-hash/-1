# VELTON v0.8 — проверка реальных составов

Дата сборки: **15 ноября 2026**. В Mini App полностью автономная футбольная симуляция: **данные один раз включены в приложение, запросов к футбольным API нет**.

## Фактический охват

- **1453 настоящих клубов** во всех 80 лигах — без изменений относительно v0.7.
- **1070** именованных записей в мастер-каталоге (бывшие снимки + новые).
- **1009** футболистов доступны при создании нового слота. Исторические игроки, отсутствующие в подтверждённой первой команде клуба, оставлены в БД для старых сохранений, но исключены из новых.
- **29 клубов** с датированными составами 2026/27, **692** футболистов, распределённых по этим клубам.
- **309** уникальных записей добавлено к v0.7, **41** существующих игрока уточнили клубную принадлежность в стартовом каталоге.

## Как предотвращаем дубли и порчу старых слотов

- Проверка по нормализованному имени в глобальной базе. Неоднозначные совпадения не переназначаются автоматически.
- `roster_verified_clubs` хранит ссылку на источник, сезон и объём заявки.
- `confirmed_2627` отмечает, кого допустимо включить в **новый** игровой мир клуба с подтверждённым составом. Остальные исторические записи в этой команде не удаляются.
- `world_players` копируется при создании карьеры. Новые данные изменяют только стартовую базу; трансферы, участники и результаты существующих карьер не переносятся в другие слоты.
- Повторная загрузка того же каталога не создаёт новых футболистов.
