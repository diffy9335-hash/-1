VELTON — ПОЛНЫЙ ПРОЕКТ ДЛЯ НОВОГО ХОСТИНГА BOTHOST
==================================================

ЭТО ПОЛНАЯ СБОРКА, НЕ ПАТЧ. Внутри есть сам бот, игра, Mini App,
все необходимые world_data и настройки Docker.

1. На Bothost СОЗДАЙ НОВЫЙ ПРОЕКТ. Выбирай тип сборки Docker / Dockerfile,
   а не старый сломанный контейнер и не автозапуск отдельного Python-скрипта.
2. Загрузи архив и РАСПАКУЙ ЕГО СОДЕРЖИМОЕ В КОРЕНЬ ПРОЕКТА.
   Корень должен выглядеть так:
      Dockerfile
      requirements.txt
      main.py
      server.py
      bot.py
      game.py
      engine.py
      world.py
      offline_catalog.py
      verified_rosters.py
      .dockerignore
      .env.example
      .env
      static/index.html
      static/app.js
      static/style.css
      world_data/league_registry.json
      world_data/packs/*.json
   НЕ создавай вложенную папку VELTON/... вокруг этих файлов.
3. В ПЕРЕМЕННЫХ ОКРУЖЕНИЯ Bothost укажи:
      BOT_TOKEN=<свой секретный токен из BotFather>
      APP_URL=https://<публичный HTTPS-домен мини-приложения>
      PORT=3000
      DEMO_MODE=0
      DB_PATH=/app/data/velton.sqlite3
   Файл .env внутри архива — пустой шаблон. Он не содержит секретов.
   Docker специально НЕ копирует .env: в Bothost эти значения нужно
   вводить в панели переменных окружения. Не присылай токен в переписку.
4. Убедись, что на новом проекте открыт HTTP-порт 3000 и доступен HTTPS-домен.
5. Нажми СБОРКА / BUILD (именно новая сборка), затем ЗАПУСК.
6. Проверь в браузере https://<домен>/api/health, затем напиши боту /start.

Если хостинг не даёт автоматически распаковать ZIP, распакуй его
у себя на компьютере и загрузи содержимое файлами/папками.

Сохранения прежнего хоста НЕ включены. Если есть файл data/velton.sqlite3,
сначала создай резервную копию и отдельно перенеси его в постоянное хранилище
нового проекта. Без переноса старые карьеры будут недоступны.

Примечание: реальные названия команд/игроков — из встроенных офлайн-снимков;
не у каждого клуба есть полный актуальный состав. Интернет нужен для Telegram
и HTTPS Mini App, но внешнего футбольного API игра не требует.
