# VELTON v0.10 — патч сопоставления настоящих клубов

Это **не полная сборка**. ZIP содержит только **два файла нового/обновлённого инструментария, один файл тестов и эту инструкцию**. Требуется уже установленный проект **VELTON v0.9**.

## Зачем обновление

В загрузчике v0.9 некоторые коды Transfermarkt были ошибочными: например, `KR1` означает **Хорватию**, а `RSK1` — **Южную Корею**. Также отсутствовали коды Сербии, Японии, Саудовской Аравии, Аргентины и ряда других лиг. Исправлены коды и добавлена **проверка страны при ручном связывании клубов**.

Главное новое удобство: можно создать CSV с непонятными названиями клубов, проверить подсказки, заполнить один столбец и импортировать проверенные соответствия. Подсказки **не применяются автоматически**. Так мы не выдаём одну команду за другую.

## Установка

1. Сделай копию каталога VELTON v0.9 и файла `velton.sqlite3` (если он у тебя уже есть).
2. Распакуй содержимое ZIP **в корневую папку VELTON v0.9**, с заменой `tools/install_real_rosters_v09.py`. Структуру подпапок `tools`, `tests`, `docs` сохраняй.
3. Никакой сторонний API или дополнительная библиотека не нужны.

## Заполнение клубов из статического источника (локально)

Сначала получи два исходных CSV через команду прежней версии:

```bash
python tools/install_real_rosters_v09.py --download
```

Если файлы уже скачаны, повторно скачивать не нужно.

Создай список клубов, которые не удалось однозначно сопоставить:

```bash
python tools/review_club_matches_v10.py prepare
```

Открой `world_data/snapshots_v09/clubs_to_review_v10.csv` в Excel или другом CSV-редакторе. Для каждого проверенного клуба можно заполнить **только** столбец `velton_club_id`; ID можно найти рядом в `suggested_clubs`. **Не копируй предложение наугад**. Незаполненные строки пропускаются.

Примени проверенные соответствия:

```bash
python tools/review_club_matches_v10.py apply
```

Инструмент сверит исходное название, ID клуба и страну, не допустит слияния двух внешних команд в одну и запишет изменения в `tools/club_aliases_v09.json` только после полной проверки CSV.

Затем пересобери пакет **без скачивания повторно**:

```bash
python tools/install_real_rosters_v09.py
```

Посмотри `world_data/snapshots_v09/velton_real_2026_07_bulk.audit.json`. Если после проверки принимаешь результаты и файл ещё не установлен:

```bash
python tools/install_real_rosters_v09.py --install
python tools/audit_squads_v09.py
```

Если пакет уже установлен раньше, скрипт намеренно не переписывает его: сделай резервную копию существующего `world_data/packs/velton_real_2026_07_bulk.json`, **вручную удали или переименуй его**, затем повтори `--install`. На работающем сервере после установки пакета нужен перезапуск. Уже созданные карьерные слоты останутся неизменными; обновление состава появится у новых слотов.

## Проверка тестов

```bash
python -m pytest -q
```

На подготовленной сборке v0.9 с этим патчем **50 тестов пройдены** (42 прежних и 8 новых).

## Реальные границы готовности

Патч улучшает **точность и охват массового импорта** при наличии исходных файлов. Он **не добавляет сам по себе** 30–40 тысяч футболистов и не делает все 1 453 клуба полностью заполненными. Предоставленный исторический источник датирован **6 июля 2026 года**, поэтому клубные переходы и составы в нём не являются подтверждёнными на сезон 2026/27. Подтверждённые заявки 2026/27 из прежней сборки имеют приоритет.

Источник: https://github.com/dcaribou/transfermarkt-datasets
