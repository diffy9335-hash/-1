# VELTON v0.9 — массовое наполнение настоящих составов

Дата: 15 ноября 2026 года.

## Что действительно содержится в архиве **до дополнительных загрузок**

- **35 футбольных стран, 80 лиг, 1 453 реально названных клуба** (из 1 504 плановых мест).
- **1 070 исторических записей имён футболистов**; **1 009 допускаются в новую карьеру** после применения приоритета официальных заявок 2026/27.
- **29 клубов** имеют датированные подтверждённые заявки 2026/27; **66 клубов** имеют хотя бы одну частичную запись; **1 358 клубов** пока без названных игроков.
- Среди 1 453 клубов **27 клубов** имеют не менее 20 футболистов (некоторые официальные заявки включают 18–19 человек, поэтому 27 не противоречит 29 подтверждённым клубам).
- Полных текущих составов всех 1 453 клубов **нет**. В этом архиве нет скачанного набора из десятков тысяч игроков.

## Что сделано в v0.9

Встроен **массовый импортер** фактических имён из двух статических CSV, которые можно загрузить **один раз** на ПК. В работающем Telegram-боте **нет** запросов к провайдерам футбольных матчей, API-ключей, нужды в статическом IP или расписаний реальных матчей.

Основной документированный источник: [dcaribou/transfermarkt-datasets](https://github.com/dcaribou/transfermarkt-datasets), проект под CC0, **срез данных до 6 июля 2026 года**. Там указано более 50 тыс. профилей игроков и более 790 клубов, однако *не все* игроки являются действующими на июль 2026 года, и клубы/заявки 2026/27 там **не охвачены**. Используются только строки с привязкой к клубу и последним сезоном не раньше 2025. Названия команд автоматически связываются только при однозначном совпадении, остальные попадут в аудит ручной проверки. Реальные рейтинги, зарплаты и стоимости из источника не переносятся: экономика остаётся симуляционной.

### Разовая установка: Windows / Linux / macOS

Распаковать проект, перейти в его каталог в терминале:

```bash
python tools/install_real_rosters_v09.py --download
```

Команда скачивает `players.csv.gz` и `clubs.csv.gz` в `world_data/snapshots_v09`, проверяет и преобразует. Необязательные файлы в сотни тысяч/миллионы строк не нужны, API-ключ и IP не требуются. После выполнения смотри `velton_real_2026_07_bulk.audit.json` и сверь неполные/неоднозначные совпадения.

Если результат устраивает, устанавливай готовый файл **только для следующих карьерных слотов**:

```bash
python tools/install_real_rosters_v09.py --install
python tools/audit_squads_v09.py
```

Первый вызов с `--download` создаёт исходные CSV, JSON-пакет и аудит. Второй использует уже скачанные файлы, повторно проверяет CSV и копирует пакет в `world_data/packs/`. Изменения применятся при **перезапуске сервера** и **создании нового** карьерного слота. Старые игровые трансферы, контракты, результаты и таблицы не переписываются.

Если скачивание невозможно на сервере — скачай `players.csv.gz` и `clubs.csv.gz` самостоятельно по адресам, опубликованным в README источника, положи их в `world_data/snapshots_v09/`, затем запусти те же команды без `--download`.

### Исправление неоднозначных названий клубов

В JSON-аудите `unmatched_clubs` содержатся внешние `club_id`, имя и подсказки для проверки. В `tools/club_aliases_v09.json` допиши **только вручную подтверждённые** соответствия числового `club_id` источника и уже существующего `club_id` VELTON, например:

```json
{"12345": "verified:ITA_1:00"}
```

Это **пример формата**; `12345` не является подтверждённым ID Atalanta и не должен использоваться без проверки. Запусти конвертер снова. Автоматически угадывать клуб по похожему написанию запрещено.

### Дополнительный источник — опционально

Можно расширить охват историческими списками FC26, если ты легально получил локальный CSV на условиях его правообладателей. Это не официальный реестр игроков 2026/27. Не используются карточные рейтинги, фото и логотипы:

```bash
python tools/import_fc26_local.py ./FC26.csv
# после проверки *.audit.json:
python tools/import_fc26_local.py ./FC26.csv --install
python tools/audit_squads_v09.py
```

Клубы без однозначного соответствия в базе не импортируются. Игроки из проверенных заявок 2026/27 не заменяются записями прошлых сезонов. Женские команды из другого футбольного реестра автоматически пропускаются, поскольку нынешние 80 лиг — мужские.

## Контроль качества и безопасность

- Нет генерации выдуманных имён под видом настоящих. Пропускаются несуществующие в реестре клубы, неоднозначные названия, конфликты имён и игроки с устаревшей `last_season`.
- У каждого импортированного футболиста есть дата/источник исторического снимка. В Mini App после импорта видно, является ли состав подтверждённой заявкой 2026/27, историческим снимком или частичным списком.
- **Общая игровая база не заменяет сохранения**; пять карьер независимы, старые результаты и трансферы не переписываются.
- Новый отчёт `docs/coverage_v09.csv` / `.json` пересчитывает все 80 лиг и 1 453 клуба. После установки дополнительных пакетов повтори аудит, чтобы увидеть реальный прирост.
- Подтверждённые заявки 29 клубов за 2026/27 приоритетнее любого исторического массового источника.
- Вход в Telegram по-прежнему требует токен BotFather и HTTPS; **для футбольных данных ключ не нужен**.

## Что нельзя честно обещать на этом этапе

Один датированный набор содержит не все клубы VELTON. Даже после разовой загрузки автоматически не появится 20–30 настоящих футболистов у каждого из 1 453 клубов. Для заполнения всех 35 стран нужны дополнительные легальные датированные источники с сопоставлением клубов. Нельзя выдавать старый список за актуальную заявку 2026/27, даже если реальные фамилии верны.

В текущем окружении внешние CSV недоступны для скачивания, поэтому здесь проверены схемы, модели клубов, импорт на локальных тестовых CSV, старые и новые карьеры, а не фактическая онлайн-загрузка всех 50 тысяч строк. Итоговый ZIP честно содержит движок, тесты, встроенные 1 070 записей и инструмент массового импорта, **не** дополненные из сети 30–40 тысяч футболистов.
